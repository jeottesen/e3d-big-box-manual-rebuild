# Notes

Results that came out of recovering the manual. None of this is needed to rebuild the site.

- `MISSING.md` – pages and images the archive does not have. Regenerated by `scripts/missing_report.py`.
- `parts.json` – the parts list of each sheet of the exploded drawings (part, quantity, bag or box), written by `scripts/drawings.py`. The sheets it could not read are listed under `problems`. `scripts/targets.py` says which build section each sheet belongs to.
- `provenance/` – which archive snapshot each page, rebuilt page, image and datasheet came from (JSON).
- `ANALYSIS.md` – a summary of how the wiki's pages changed over time: what moved, what was removed, what looks broken. Written by a small model from the diffs, then checked against the pages; its corrections section lists what the check found wrong.
- `CLEAN_REPORT.md` – the clean-up of the saved versions: which versions were error pages or text-identical duplicates.
- `history/` – the evidence behind `ANALYSIS.md`: `SUMMARY.md` lists each page's versions and line changes, and `diffs/` has the text diff between consecutive versions of each page.

`ANALYSIS.md`, `CLEAN_REPORT.md` and `history/` come from a one-off pass over the wiki's full edit history, about 250 archived versions, using two scripts (`versions.py` and `clean.py`) that are no longer in `scripts/`. Building the manual does not need that history, so the build only fetches the pages it uses. The two scripts are in this repository's git history, in pull request #1.
