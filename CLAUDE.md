# CLAUDE.md

E3D BigBox 3D printer manual, recovered from the Wayback Machine. See README.md for the overview and NOTICE.md for attribution.

## Layout

- `manual/` – the manual as Markdown plus images (browsable on GitHub)
- `docs/` – the HTML build, for GitHub Pages later
- `scripts/` – recovery and build scripts (Python, standard library only)
- `notes/` – what is missing, the history analysis, and which archive snapshot each page and image came from

## Rules

- Keep the CC BY 3.0 attribution in NOTICE.md. Any new recovered content must be covered by it.
- Don't commit the raw archive data (saved page versions, CDX inventories, raw HTML). It lives outside the repo and is rebuilt by the scripts.
- `manual/` and `docs/` are generated by the scripts. Change the scripts, not the output.
- Don't add the version-browsing web server to this repo.
- Be polite to the Wayback Machine: one connection, a delay between requests, back off on errors, stop after repeated failures.
- Work on a branch and open a pull request. Don't push to `main`.
