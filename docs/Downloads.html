Simplify3D profiles

The Software page offered Simplify3D profiles, but the files were hosted on the wiki and are gone. The BigBox repository has profiles, and a community repository has a second set whose settings follow the material, quality and extruder you choose. The original profiles, including the experimental dual one, are under "Archived copies from the old E3D file server" below.

  • BigBox Pro.fff – BigBox3D/Simplify3D
  • BigBox Dual.fff – BigBox3D/Simplify3D
  • BigBox Hybrid-Pro.fff – BigBox3D/Simplify3D
  • BigBox Hybrid-Dual.fff – BigBox3D/Simplify3D
  • BigBox Print Farm.fff – BigBox3D/Simplify3D
  • BigBox-Settings: README – Alex9779/BigBox-Settings; explains the profiles
  • BigBox Pro.fff – Alex9779/BigBox-Settings
  • BigBox Dual.fff – Alex9779/BigBox-Settings
  • BigBox Hybrid-Pro.fff – Alex9779/BigBox-Settings
  • BigBox Hybrid-Dual.fff – Alex9779/BigBox-Settings
  • BigBox Hybrid-Dual Mirrored.fff – Alex9779/BigBox-Settings
  • BigBox Dual Titan.fff – Alex9779/BigBox-Settings
  • BigBoxBedAssembly.stl – a model of the BigBox bed for Simplify3D; Alex9779/BigBox-Settings

Firmware

Precompiled Marlin builds for each BigBox version, from the BigBox firmware repository. The mesh bed levelling builds need the IR sensor moved to the heated bed.

  • marlin_direct_dual.hex – BigBox v1.0 Dual (Direct Dual), Kickstarter
  • marlin_direct_pro.hex – BigBox v1.0 Pro (Direct Pro), Kickstarter
  • marlin_hybrid_dual.hex – BigBox v1.1 Dual Hybrid (Titan and non-Titan), auto bed levelling
  • marlin_hybrid_pro.hex – BigBox v1.1 Pro Hybrid (Titan and non-Titan), auto bed levelling
  • marlin_hybrid_dual_mesh.hex – BigBox v1.1 Dual Hybrid, mesh bed levelling
  • marlin_hybrid_pro_mesh.hex – BigBox v1.1 Pro Hybrid, mesh bed levelling
  • Firmware README – which file is for which version, and how to flash it
  • BigBox Marlin source – one branch per BigBox version (GPL v3)

Archived copies from the old E3D file server

The wiki's own file server (files.e3d-online.com) is gone, but the Wayback Machine kept these. The links go to the archived copies.

  • bigbox_pro.fff – Simplify3D profile for the Pro
  • bigbox_dual.fff – Simplify3D profile for the Dual
  • bigbox_dual_experimental.fff – the experimental dual-extruder Simplify3D profile described in the appendix
  • bigbox_hybrid.fff – Simplify3D profile for the Hybrid
  • bigbox_1.1.fff – Simplify3D profile for BigBox 1.1
  • BigBox_Slic3r_config_bundle.ini – Slic3r configuration bundle
  • BigBox_Cura_0.10.ini – Cura configuration, 0.10 layer height
  • BigBox_Cura_0.20.ini – Cura configuration, 0.20 layer height
  • BigBox_Cura_0.25.ini – Cura configuration, 0.25 layer height
  • EXPLODED_DRAWINGS.pdf – BigBox exploded drawings
  • Titan_Assembly_Supplementary.pdf – Titan assembly supplementary instructions (the wiki linked it with spaces in the name)
  • ASM_EX_THUMB_SCREW.stp – Titan thumb screw CAD model
  • ASM_EX_AERO_285.stl – Titan Aero 2.85 mm model
